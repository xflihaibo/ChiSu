# ChiSu (尺素) - 专业级开发者浏览器插件

ChiSu (尺素) 是一款为前端开发者和设计师量身定制的沉浸式 Chrome 扩展工具。它集成了高精度像素测量、实时颜色提取和深度的盒子模型审查功能，旨在提升日常 UI/UX 开发效率。

## 🌟 核心功能

### 1. 测量模式 (Ruler Mode) - 快捷键 `1`
*   **像素刻度尺**：在页面顶部和左侧显示精准的像素刻度。
*   **多重标线**：从刻度尺向内拖动即可生成无限量的水平或垂直参考线。
*   **距离自动测量**：多条标线之间会自动显示像素距离，方便核对间距。
*   **持久化与重拖拽**：标线放置后可再次选中并重新调整位置。

### 2. 取色模式 (Picker Mode) - 快捷键 `2`
*   **实时放大镜**：10 倍放大效果，带精准十字准星，确保像素级取色。
*   **多格式支持**：按下 `F` 键可在 HEX、RGB 和 HSL 格式间自由切换。
*   **一键复制**：点击鼠标即可将颜色代码复制到剪贴板，并带有成功提示。

### 3. 审查模式 (Inspector Mode) - 快捷键 `3`
*   **盒子模型可视化**：鼠标悬停时自动显示元素的 Margin（橙色）和 Padding（绿色）区域。
*   **详尽属性卡片**：点击元素即可锁定信息卡片，查看字体、字号、字重、行高及颜色。
*   **全属性复制**：卡片内所有属性值均支持点击复制。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| **Esc** | 开启 / 关闭 ChiSu 沉浸模式 |
| **1** | 切换至 **测量模式** (Ruler) |
| **2** | 切换至 **取色模式** (Picker) |
| **3** | 切换至 **审查模式** (Inspector) |
| **F** | (取色模式下) 切换颜色格式 (HEX/RGB/HSL) |

## 🛠️ 技术栈

*   **构建工具**: Vite + @crxjs/vite-plugin
*   **语言**: TypeScript
*   **核心技术**: 
    *   **Shadow DOM**: 实现插件 UI 与原网页样式的完全隔离，防止样式冲突。
    *   **Canvas API**: 实现高性能的刻度尺渲染、网格绘制及盒子模型高亮。
    *   **Chrome Extension API (V3)**: 利用 `captureVisibleTab` 实现高精度的像素采样。

## 🚀 安装与开发

### 开发者安装步骤
1. 下载或克隆本项目。
2. 在项目根目录运行 `npm install` 安装依赖。
3. 运行 `npm run build` 进行项目打包。
4. 打开 Chrome 浏览器，访问 `chrome://extensions/`。
5. 开启右上角的“开发者模式”。
6. 点击“加载已解压的扩展程序”，选择本项目中的 `dist` 目录。

### 常用命令
*   `npm run dev`: 启动开发模式（热重载）。
*   `npm run build`: 构建正式版本。
